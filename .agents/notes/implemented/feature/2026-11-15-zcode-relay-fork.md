# Agent Note: 智谱中继 fork 与独立 Android 更新身份

Status: implemented

## 问题

用户需要原 Codex Mobile Bridge 功能与后续上游更新，同时只走智谱国内中继。早期 2.0.3 本地包版本码低于用户已有 2.2.1，安装被拒绝；复刻云端聊天页面也遗漏原项目功能。

## 决策

维护保留上游历史的 `zcode-relay` 分支，真实合并 v2.2.1；原版 Web 与共享移动资源保持上游。新增传输模块连接智谱云与固定本机网关，不改变原 Desktop owner。Android 使用独立包名与固定私有签名，与原版并存；后续合并上游、测试、重建并用相同签名发布。

手机与电脑的移动更新源只接受本 fork，电脑协助更新额外声明并校验 repository，避免从旧网关下载回官方签名 APK。分发不包含账号凭据、用户聊天或签名私钥。

## 备选方案

继续仿制云端页面会重复维护业务；使用同包名加大版本码仍无法解决签名不一致；要求卸载原 App 会丢失原有数据。独立包名保留用户原 App，只需首次重新连接。

## 影响

fork 可以持续合并原项目，但上游更新不会自动完成冲突处理和手机发包。首次安装智谱版不自动迁移原版绑定或草稿。签名密钥需私下备份，后续覆盖升级必须重用。正式服务升级与手机蜂窝验收分别记录。

## 验证

执行记录见本轮交付验收与 Git 提交。包含 Android 编译、签名与包元数据、手机源码回归、更新源隔离、智谱协议和历史读取；不以编译代替安卓真机安装与蜂窝验收。
